쿨브리핑 v1.16.3 — 배포 전 테스트용 폴더
(아직 선생님들께 배포되지 않았습니다. 이 폴더에서 테스트해 보고 괜찮으면 배포하세요.)

■ 이번 버전에서 바뀐 것
 0. [v1.16.3] NEIS 인증키·구글 연결 정보를 코드(깃허브)에서 뺐습니다. 이제 선생님 PC에만 둡니다.
    구글 캘린더 오류 문구가 실제 원인(예: Calendar API가 꺼져 있음)과 구글 응답 코드를 보여 줍니다.
    [v1.16.2] 테스트 폴더에서 구글 연결 정보가 없으면 설정에 '⚠ 파일 없음' 카드로 알려 줌
    [v1.16.1] 일정 화면에서 마감일 있는 날짜를 누르면 깨지던 문제 고침
 1. 📨 전달 메시지 — 버튼을 누르면 창이 바로 열림. [✨ 만들기]를 눌러야 만들어짐 → [🔄 다시 만들기].
 2. ⭐ 메시지 즐겨찾기 — 메시지마다 ☆/★, '⭐ 즐겨찾기' 탭.
 3. 📖 사용설명서 — 사이드바 '설정' 바로 아래.
 4. 📅 구글 캘린더 — 학교 계정 연결, [📅 일정에 넣기], 휴대폰과 날짜·삭제·완료(✓) 연동.

■ 테스트 전에 '쿨메시저 알림장' 폴더에 둘 파일 (한 번만, 깃허브에는 안 올라감)
 - client_secret_….json : 구글 클라우드에서 받은 파일 그대로 (구글 캘린더용)
 - neis_api_key.txt     : NEIS 인증키 한 줄만 적은 메모장 파일 (학사일정용)
 [테스트_실행.bat]이 이 두 파일을 찾아 이 버전 폴더 안에만 섞어서 넣습니다.

■ 실행 방법
 1. 트레이의 쿨브리핑 아이콘 → 종료 (한 번에 하나만 실행되기 때문)
 2. 이 폴더의 [테스트_실행.bat] 더블클릭
    - 검은 창에 '구글 연결 정보: 있음', 'NEIS 인증키: 있음'이 나오는지 확인
    - 처음 한 번만, 필요하면:  pip install -r requirements.txt
 3. 테스트 버전은 설치된 쿨브리핑과 데이터가 따로입니다(%LOCALAPPDATA%\CoolBriefingTest\v1.16.3).
    가짜 메시지(데모 모드)로 시작하고, Gemini 키는 지금 쓰는 것을 그대로 씁니다.
 4. 끝나면 시작 메뉴 → 쿨브리핑으로 원래 앱을 다시 켜세요.

■ 구글 캘린더에서 오류가 나면
 - 오류 문구 끝의 '(구글 응답: …)'까지 그대로 알려 주세요. 어느 단계 문제인지 바로 압니다.
 - 'Google Calendar API가 켜져 있지 않아요'면: 구글 클라우드 → API 및 서비스 → 라이브러리 →
   Google Calendar API → [사용]. 켠 직후면 5분쯤 뒤 다시.

■ PC 클로드 코드에 맡길 때 (복사해서 붙여 넣기)
 쿨브리핑 v1.16.3 테스트 — 바탕 화면\클로드 코워크 사용폴더\쿨메시저 알림장\v1.16.3 폴더에서
 테스트_실행.bat으로만 실행. 배포 금지(release.ps1·build.ps1 실행 금지, master 병합 금지),
 이 폴더의 코드를 직접 고치지 말고 결과만 보고.
 개인정보: [TEST] 데이터로만, 캡처는 앱 창 단위로만. 학교 계정 이메일이 보이는 화면은 가리고 찍기.
 client_secret·neis_api_key.txt 내용은 화면·대화·로그 어디에도 그대로 옮기지 말 것.
 확인 항목(실패하면 어느 단계에서 막혔는지 짚어서 보고):
  1) 검은 창의 '구글 연결 정보/NEIS 인증키: 있음' 두 줄
  2) 일정 화면: 마감일 있는 날짜를 눌러도 오른쪽 목록이 정상(v1.16.1 고침 확인), 학사일정 표시
  3) 전달 메시지, 즐겨찾기, 사용설명서 (v1.16.0 항목 그대로)
  4) 구글 캘린더: 연결 → 쿨브리핑 캘린더 만들기 → [TEST] 메시지 '📅 일정에 넣기' → 넣기 → 초록 버튼 →
     같은 메시지 다시 넣으면 '고치기' → 휴대폰에서 날짜 옮기고 [🔄 지금 맞추기] → 마감일 변경 →
     휴대폰에서 삭제 → 연결만 풀림 → 업무 완료 시 ✓ / 되돌리면 ✓ 사라짐 → 다른 일정 보기·연결 끊기.
     오류가 나면 문구 끝 '(구글 응답: …)'과 검은 창의 '[구글 캘린더 API 오류]' 줄을 그대로 보고.

■ 괜찮으면 배포 (이 폴더가 아니라 저장소에서)
 1. 저장소 루트에 secrets 폴더를 만들고 client_secret_….json 과 neis_api_key.txt 를 넣기
    (깃허브에 안 올라감. 없으면 build.ps1이 멈춰서 기능 빠진 설치 파일이 나가지 않음)
 2. 브랜치 feature/v1.16-calendar-favorites-manual 을 master에 병합
 3. release.ps1 -Version 1.16.3 -Notes "…"  로 배포 (1.16.0~1.16.2는 배포하지 않고 건너뜀)
 고칠 점이 있으면 알려 주세요 — 고친 버전은 v1.16.4 폴더로 자동으로 생깁니다
 (쿨메시저 알림장 폴더의 [새_버전_폴더_받기.bat], 또는 자동 확인을 켰다면 컴퓨터 켤 때).
