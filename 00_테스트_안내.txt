쿨브리핑 v1.16.2 — 배포 전 테스트용 폴더
(아직 선생님들께 배포되지 않았습니다. 이 폴더에서 테스트해 보고 괜찮으면 배포하세요.)

■ 이번 버전에서 바뀐 것
 0. [v1.16.2] 구글 연결 정보 파일(client_secret_….json)을 '쿨메시저 알림장' 폴더에 받은 이름
    그대로 넣기만 하면 됨. 파일이 없으면 설정에 '구글 캘린더 (테스트) ⚠ 파일 없음' 카드가 보임.
    [v1.16.1 고침] 일정 화면에서 업무 마감일이 있는 날짜를 누르면 화면이 깨지던 문제
    (v1.16.0 테스트에서 발견). 아래 1~4는 v1.16.0과 같음.
 1. 📨 전달 메시지 — 버튼을 누르면 창이 바로 열림. 받는 사람만 골라서는 만들어지지 않고
    [✨ 만들기]를 눌러야 만들어짐. 만든 뒤에는 [🔄 다시 만들기].
 2. ⭐ 메시지 즐겨찾기 — 메시지마다 ☆/★, '⭐ 즐겨찾기' 탭.
 3. 📖 사용설명서 — 사이드바 '설정' 바로 아래.
 4. 📅 구글 캘린더 — 학교 계정 연결, 카드의 [📅 일정에 넣기], 휴대폰과 날짜·삭제·완료(✓) 연동,
    일정 화면의 [🔄 지금 맞추기]·'다른 일정도 보기'.

■ 실행 방법
 1. 작업 표시줄 오른쪽 트레이의 쿨브리핑 아이콘 → 종료 (한 번에 하나만 실행되기 때문)
 2. 이 폴더의 [테스트_실행.bat] 더블클릭
    - 처음 한 번만, 명령 프롬프트에서:  pip install -r requirements.txt
 3. 테스트 버전은 설치된 쿨브리핑과 데이터가 완전히 따로입니다.
    - 데이터 위치: %LOCALAPPDATA%\CoolBriefingTest\v1.16.2
    - 가짜 메시지(데모 모드)로 시작, 첫 설정 창·'자동 시작' 등록 없음
    - Gemini API 키는 지금 쓰시는 것을 그대로 씀
 4. 테스트가 끝나면 설치된 쿨브리핑을 다시 켜세요(시작 메뉴 → 쿨브리핑).

■ 구글 캘린더까지 테스트하려면
 - 구글 클라우드 콘솔에서 받은 client_secret_….json 파일(보통 '다운로드' 폴더)을
   '쿨메시저 알림장' 폴더(버전 폴더들이 있는 곳)에 이름 그대로 넣고 [테스트_실행.bat]을 실행.
   검은 창에 '구글 캘린더: 켜짐'이 나오면 설정 → 구글 캘린더 카드가 보입니다.
 - 이 파일이 없으면 구글 캘린더 버튼·메뉴가 아예 안 보이는 게 정상입니다.
 - 일정은 새로 만든 '쿨브리핑' 전용 캘린더에만 넣고, 끝나면 [TEST] 일정은 지우세요.

■ PC 클로드 코드에 맡길 때 (복사해서 붙여 넣기)
 쿨브리핑 v1.16.2 테스트 — 바탕 화면\클로드 코워크 사용폴더\쿨메시저 알림장\v1.16.2 폴더에서
 테스트_실행.bat으로만 실행. 배포 금지(release.ps1·build.ps1 실행 금지, master 병합 금지),
 이 폴더의 코드를 직접 고치지 말고 결과만 보고.
 개인정보: [TEST] 데이터로만, 캡처는 앱 창 단위로만. 학교 계정 이메일이 보이는 화면
 (브라우저 로그인, 구글 캘린더 연결 창, 일정 화면 위쪽 막대)은 캡처하지 않거나 가리고 찍기.
 확인 항목(실패하면 어느 단계에서 막혔는지 짚어서 보고):
  1) google_client.json 없을 때 구글 캘린더 버튼·설정 카드·일정 화면 막대가 안 보이는지
  2) 전달 메시지: 창 바로 열림 / 받는 사람만 골라서는 안 만들어짐 / [✨ 만들기]→[🔄 다시 만들기] /
     민감 메시지는 만들기 전에 확인 창
  3) 즐겨찾기 ☆→★, '⭐ 즐겨찾기 N' 숫자, 빈 탭 안내 / 사용설명서 위치·검색·장 사이 링크
  4) 구글 캘린더: 학교 계정 로그인 성공·개인 gmail 거부 → 쿨브리핑 캘린더 만들기 →
     [TEST] 메시지 카드 '📅 일정에 넣기' → 후보 고쳐서 넣기 → 버튼 초록 '캘린더에 있음 ✓' →
     같은 메시지로 다시 넣으면 '고치기'(중복 없음) → 휴대폰에서 날짜 옮기고 [🔄 지금 맞추기] →
     업무 마감일 변경+토스트 → 휴대폰에서 삭제 → 업무는 남고 연결만 풀림 → 업무 완료 시
     제목 앞 ✓ / 되돌리면 ✓ 사라짐 → '다른 일정도 보기', 내 캘린더 목록 고르기, 캘린더 ID 입력, 연결 끊기
